# Cobol_Exercise
Repositorio de Prácticas COBOL  Este repositorio contiene ejercicios básicos y prácticos desarrollados en el lenguaje COBOL. El objetivo es servir como un espacio de aprendizaje y práctica para quienes desean iniciarse o reforzar sus conocimientos en programación COBOL, desde conceptos fundamentales hasta ejemplos aplicables en entornos reales.
